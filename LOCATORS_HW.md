# Практическое задание: поиск CSS и XPath локаторов

## Описание

В этом задании вам нужно потренироваться искать локаторы для элементов на странице.

Локаторы — это один из базовых инструментов в UI-автоматизации. С их помощью автотесты находят кнопки, поля ввода, карточки, заголовки, изображения и другие элементы интерфейса.

В рамках задания нужно попрактиковаться с двумя типами локаторов:

- CSS selector;
- XPath.

---

## Часть 1. Практика CSS-селекторов

Перейдите на сайт:

**https://flukeout.github.io/**

Этот тренажёр помогает отработать базовые и продвинутые CSS-селекторы.

Нужно пройти все упражнения и потренироваться искать элементы с помощью CSS.

---

## Часть 2. Практика XPath

Перейдите на сайт:

**https://topswagcode.com/xpath/**

Этот тренажёр помогает отработать поиск элементов через XPath.

Нужно потренироваться писать XPath-локаторы для разных элементов страницы.

---

## Часть 3. Поиск локаторов XPATH и CSS

Перейдите на сайт:

**https://testsmith-io.github.io/locator-game/**

В этой игре нужно находить элементы на странице и подбирать для них стабильные локаторы.

Для каждого найденного элемента нужно подобрать:

- CSS-локатор;
- XPath-локатор.

## Дополнительное задание со звёздочкой

### Написать автотест на проверку карточек

Нужно написать автотест, который проверяет отображение информации по карточке на странице.

Сайт:

**http://localhost:3000/**

#### Что должен делать тест

1. Открыть страницу с банковскими картами.
2. Нажать на кнопку для загрузки карточек.
3. Проверить, что блок с карточками отображаются.

Написать автотест нужно в 2ух вариантах 
1. CSS-локаторы
2. XPath-локаторы



#### Отчет по домнему заданию 

1. Скриншоты с пройденными заданиями
2. ПР с автотестом
 

## Критерии успешного выполнения

Задание считается выполненным, если:

- пройдена практика на CSS-селекторах;
- пройдена практика на XPath;
- для элементов найдены CSS и XPath локаторы;
- для задания со звёздочкой написан автотест на проверку отображения карточек.
