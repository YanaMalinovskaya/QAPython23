# Практическое задание: тестирование коллекции мемов с помощью pytest

## Описание

В этом задании вам нужно протестировать класс `MemeCollection`, который хранит коллекцию мемов.

Каждый мем содержит:

- название;
- категорию;
- количество лайков.

Класс умеет добавлять мемы, искать мемы по категории, находить самый популярный мем и очищать коллекцию.

Задача направлена на практику работы с:

- фикстурами pytest;
- параметризацией тестов;
- проверкой позитивных и негативных сценариев;
- поиском ошибок в готовой реализации.

## Что нужно сделать

Создайте файл с тестами и напишите автотесты для класса `MemeCollection`.

### 1. Создайте фикстуры

Нужно подготовить 3 фикстуры:

- **Фикстура**, которая создаёт и возвращает пустую коллекцию мемов.
- **Фикстура**, которая создаёт коллекцию и заранее добавляет в неё несколько мемов.
- **Фикстура**, которая очищает коллекцию после прохождения теста.

Например, коллекция может содержать мемы разных категорий: `"коты"`, `"видео"`, `"игра"`, `"ситуация"`.

### 2. Проверьте базовое поведение коллекции

Напишите тесты, которые проверяют:

- новая коллекция мемов пустая;
- подготовленная через фикстуру коллекция содержит мемы;
- новый мем успешно добавляется в коллекцию;
- после добавления количество мемов увеличивается на 1;
- данные добавленного мема сохраняются корректно: `title`, `category`, `likes`.

### 3. Проверьте поиск по категории

Напишите тесты для метода `get_by_category`.

Нужно проверить два сценария:

- **Категория существует** — метод возвращает список мемов этой категории.
- **Категория не существует** — метод возвращает пустой список.

### 4. Проверьте поиск самого популярного мема

Напишите тесты для метода `get_most_popular`.

Нужно проверить три сценария:

- в коллекции нет мемов — метод возвращает `None`;
- в коллекции несколько мемов с разным количеством лайков — метод возвращает мем с максимальным количеством лайков;
- в коллекции несколько мемов с одинаковым количеством лайков — метод возвращает один из мемов с этим значением.

### 5. Проверьте очистку коллекции

Напишите тест, который:

1. берёт заполненную коллекцию;
2. вызывает метод `clear`;
3. проверяет, что после очистки список мемов пустой.

### 6. Проверьте валидацию входных данных

Метод `add_meme` должен принимать только корректные данные.

Требования к данным:

- `title` должен быть строкой;
- `category` должен быть строкой;
- `likes` должен быть числом;
- `title` не должен быть пустым;
- `category` не должен быть пустым;
- `likes` не должен быть отрицательным;

Для проверки этих сценариев используйте `pytest.mark.parametrize`.

## Тестовый класс: 

```python

class MemeCollection:
    def __init__(self):
        self.memes = []

    @staticmethod
    def _validate_meme_data(title, category, likes):
        if not isinstance(title, str):
            return "title должен быть строкой"

        if not isinstance(category, str):
            return "category должен быть строкой"

        if not isinstance(likes, str):
            return "likes должен быть строкой"

        if title.strip() == "":
            return "title не должен быть пустым"

        if category.strip() == "":
            return "category не должен быть пустым"

        if likes.strip() == "":
            return "likes не должен быть пустым"

        if not likes.strip().isdigit():
            return "likes должен быть строкой с числом"

        return True

    def add_meme(self, title, category, likes):
        result = self._validate_meme_data(title, category, likes)

        if result is not True:
            return result

        self.memes.append({
            "title": title,
            "category": category,
            "likes": likes
        })

        return "Success"

    def get_by_category(self, category):
        return [
            meme for meme in self.memes
            if meme["title"] == category
        ]

    def get_most_popular(self):
        if not self.memes:
            return None

        return min(self.memes, key=lambda meme: int(meme["likes"]))

    def clear(self):
        self.memes.pop()
```
